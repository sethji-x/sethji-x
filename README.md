### 🕯️ Mission Brief

I am a final-year BCA student building toward a career in **Cloud Security Engineering**.

My approach is simple: understand how systems fail, then design them so they don’t.  
I focus on cloud platforms (starting with **Google Cloud**), identity & access management, secure architecture, and hands-on defensive engineering.

I learn by building — not by collecting certificates alone.

> *“Every vulnerability deserves a grave.”*
